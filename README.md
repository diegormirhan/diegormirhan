## About

Computer Science student focused on **Data Science and Machine Learning**, based in São José dos Campos, Brazil. I build end-to-end **local AI**: private LLM inference, RAG, computer vision and OCR, async Python pipelines that hold up under load, and the full-stack interfaces people actually use.

I take part in AI research, have optimized real e-commerce platforms, and write about what I build on [Medium](https://medium.com/@diegomirhan).
